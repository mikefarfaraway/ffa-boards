# ffa-boards

Far Far Away Co. 내부 공유용 HTML 보드 모음 (광고 성과·분석 리포트).
GitHub Pages로 띄움: https://mikefarfaraway.github.io/ffa-boards/

- 보드마다 폴더 하나: `주제-MMDD/index.html` (+ 영상·이미지)
- 새 보드를 추가하면 루트 `index.html` 목록 맨 위에 한 줄 추가
- 링크를 아는 사람은 누구나 열 수 있음 → 민감 정보(계정번호, 잔액, 개인정보)는 넣지 않기. 검색 차단(noindex, robots.txt)만 적용됨
